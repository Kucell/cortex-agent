## Findings

### Passed

- `invoke()` 完整实现：spawn `dsh` + JSON-RPC 请求（stdin）+ stdout/stderr 累积 + timeout race + atomic journal。
- 6 类失败模式全部覆盖：spawn 缺失 → `ERR_ADAPTER_SPAWN`；非零退出 → `ERR_DISPATCH_FAILED`（含 `exit_code`/`signal`/stderr 摘录）；超时 → `ERR_DISPATCH_TIMEOUT`（SIGTERM → 1.5s SIGKILL 兜底）；坏 JSON → `ERR_JSONRPC_PARSE`（含 stdout 摘录）；JSON-RPC error envelope → `ERR_DSH_<code>`；rollback 写失败 → `rollback-failed.json` + `notify_parent: true`。
- `cancel()`：`_subprocesses` Map 跟踪；SIGTERM 后 untrack；未知 runId 返回结构化 no-op。
- `report()`：扩展 BaseAdapter，附加 `adapter_type` + 顶层 `latency_ms`（与 codex.js 对齐）。
- `_parseJsonRpc()`：支持 plain JSON / Content-Length CRLF framing / LF framing。
- 安全边界：journal 内容无 DSH session storage 引用；runtime 不触碰 `~/.dsh/sessions/`。
