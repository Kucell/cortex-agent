## FSM 5 状态 (F-006 parent-resume client)

| State | 触发 event | 转换到 | 副作用 |
| :--- | :--- | :--- | :--- |
| INIT | `eb:subagent_spawned` | RECEIVED | 写 P-003 inbox (sub-spawn 事件) |
| RECEIVED | `eb:subagent_progress` | ACKED | 更新 progress (无副作用) |
| ACKED | `eb:subagent_completed` | RUNNING → DONE | 触发父 mission resume + 写 P-003 inbox (sub-done) |
| ACKED | `eb:subagent_failed` | RUNNING → FAILED | 触发父 mission resume + escalate decision + 写 P-003 inbox |
| ACKED | `eb:subagent_cancelled` | RUNNING → DONE | 触发父 mission resume + 写 P-003 inbox |
