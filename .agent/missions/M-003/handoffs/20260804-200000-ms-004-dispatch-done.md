**3 协议统一 API**:
```js
// Caller specifies protocol, rest is unified
await dispatchExecuteProtocol({
  protocol: "http" | "cli" | "file",
  projectRoot, runId, agentType, configRef, credentialRef,
  timeout, maxRetries, backoffMs, decision,
  // protocol-specific:
  // HTTP: url, method, headers, body
  // CLI:  bin, args, env, payload, shell, cwd
  // file: configPath, outputPath, payload
});
```

**3 协议统一 journal** (`.agent-runtime/dispatch/<run_id>/`):
- `request.json` — 审计 trail, written BEFORE first attempt, 含 `protocol` field + protocol-specific config
- `result.json` — on success (2xx) terminal state
- `error.json` — on any failure terminal state
- `rollback.json` — always written, status: "completed" (success) or "rolled_back" (failure)
- `rollback-failed.json` — written if `rollback.json` write itself fails, `notify_parent: true`

**3 协议统一 retry + decision** (per D-FAE-002-4):
- Default 3 retry (cap), exponential backoff (200ms → 5s cap)
- `defaultDecisionProtocol(attempt, err)` classifies: retry / rollback / abort
- CLI: TIMEOUT/EXIT_NONZERO/SPAWN retry; PARSE/RPC_ERROR rollback; PROTOCOL abort
- file: *_NOT_FOUND/INVALID_JSON/OUTPUT_WRITE_FAILED rollback; PROTOCOL abort
- HTTP: 5xx retry; 4xx (except 408/429) abort; 网络错误 retry
- All 3 share same `dispatchExecuteProtocol` retry loop + `_writeErrorAndRollbackProtocol` 3-stage fallback

**3 协议 transport 实现细节**:

**CLI protocol** (`cliRequest`):
- spawn subprocess (shell:true default for PATH compat, shell:false for test inject)
- write JSON-RPC body to stdin
- parse stdout (3 shapes: plain JSON / CRLF frame / LF frame)
- 7 error codes: ERR_CLI_PROTOCOL / SPAWN / STDIN / TIMEOUT / EXIT_NONZERO / PARSE / RPC_ERROR
- 1.5s SIGKILL grace after SIGTERM (per D-FAE-002-4 + claude-code.js pattern)
- Tracks subprocess for potential cancel (via _subprocesses Map)

**file protocol** (`fileRequest`):
- read config JSON (atomic via fs.readFileSync)
- write result JSON (atomic via .tmp-<pid>-<ts> + rename)
- 4 error codes: ERR_FILE_PROTOCOL / CONFIG_NOT_FOUND / CONFIG_INVALID_JSON / OUTPUT_WRITE_FAILED
- Creates output dir if missing (recursive mkdir)
- Returns statusCode: 200 with config + payload + written_at

**HTTP protocol** (existing, zero modify):
- Uses `httpRequest` (existing transport)
- `dispatchExecuteProtocol({ protocol: "http", ... })` routes through same retry loop
- 21 existing tests (`agent-dispatch-execute.test.js`) pass without modification
