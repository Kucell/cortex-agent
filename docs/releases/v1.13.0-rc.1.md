#### 3. 安装配置可移植性(M-SETUP-PORT-001)
- **问题根因**:`lib/setup.js:875-890` 的 `linkGlobalConfig()` 用 `os.homedir()` 拼绝对路径,在跨用户/跨机器/跨容器(DevContainer / Codespaces / Docker)三种场景立即断链
- **修复方案**:
  - 改用 `path.relative(canonical agentDir, realHomeAgent)` 生成**相对路径** symlink
  - 立即 `realpathSync` 验证 link 可解析
  - 处理 4 种重建场景:link 不存在 / link 已对 / link target 错 / link 断链
- **`.gitignore` 加 `.agent/global`**:含 2 行注释(绝对路径跨用户断链 + 相对路径每机不同)
- **`cortex-agent doctor` 加 `[setup-portability]` 4 类检查**:
  - `missing`(缺失) / `not-symlink`(非 symlink) / `broken`(断链) / `wrong-target`(target 错)
  - 报告 + 修复建议(`--fix --yes` 留给 MS-002)
- **6 个新测试**(`tests/setup-link-global-config.test.js`):覆盖 no-op / 全新创建 / 已对不重建 / 错 target 重建 / 断链重建 / realpath 后置验证
- **e2e 验证**:`/tmp` 临时项目跑 linkGlobalConfig → readlink = 相对路径 → `git check-ignore` 命中 → realpath 解析 → doctor 段显示 ok
- **实施中修 2 个 task 外的真实 bug**:
  - macOS `/tmp → /private/tmp` 别名陷阱(需 realpath 双方再算)
  - `fs.existsSync` 跟随 symlink 跟 broken symlink 检测(需改 lstatSync)
- 文档同步 `docs/platform-integration.md` 新增"全局配置 symlink 与可移植性"小节
- commit: `1e736f2` / `dde5cf5` (merge)

### Major Features

#### 1. Cross-Project Event Bridge (P-003) — New Capability
- **Phase 1 — Module layer**: `lib/cross-project/subscriptions.js` (225 lines) + bridge event module layer
- **Phase 1 — CLI routing**: `bridge` CLI subcommand (7 tests) subscription → inbox delivery closed loop
- **Phase 2 — Handoff metadata extension**: `lib/runtime-adapters/cross-host-handoff.js` adds 4 fields:
  - `origin_project` / `target_project` (project topology)

- commits: `0d3b582` / `8031a1e` / `d77b7af` / `abccdaf` (merge)

#### 2. AGENTS.md Compatibility Adapter (T-CAB-001)
- **P0/P1 — AGENTS.md Compatibility Bootstrap managed block**: `## Compatibility Adapter Bootstrap` block enforces host workflow
  - After host identifies a command via `.agents/skills/source-command-<command>`, it **MUST** first load `.agent/workflows/<command>.md` truth source
  - If truth workflow is missing, host must report "adapter-vs-truth mismatch" and **stop** — no fallback to adapter copy
- `lib/setup.js` adds 3 functions: `compatibilityAdapterBootstrapSection` / `needsCompatibilityAdapterBootstrapMerge` / `ensureCompatibilityAdapterBootstrapEntry`
- `lib/commands.js` init + upgrade path integration
- Bilingual templates `templates/{en,zh}/.agent/rules/core-principles.md` add **principle 11** (Adapter Truth-Source Regression)
- **`fix(host-adapter): preserve upgrade additive-only boundary`**: fix upgrade path only triggers on fullUpdate + add `ctx.command === "update"` guard in update subcommand
- 6 new tests (`tests/upgrade-dry-run.test.js`)
- commits: `1ce7a95` / `dc8615e` / `ce8f5b8` (merge)

#### 3. Setup Portability (M-SETUP-PORT-001)
- **Root cause**: `lib/setup.js:875-890` `linkGlobalConfig()` uses `os.homedir()` to construct absolute path, breaks across users / machines / containers (DevContainer / Codespaces / Docker)
- **Fix**:
  - Switch to `path.relative(canonical agentDir, realHomeAgent)` for **relative path** symlinks
  - Immediate `realpathSync` validation
  - Handle 4 rebuild scenarios: missing / correct / wrong target / broken
- **`.gitignore` adds `.agent/global`**: with 2-line comments (absolute path breaks across users + relative path differs per machine)
- **`cortex-agent doctor` adds `[setup-portability]` 4-class check**:
  - `missing` / `not-symlink` / `broken` / `wrong-target`
  - Report + remediation hint (`--fix --yes` left for MS-002)
- **6 new tests** (`tests/setup-link-global-config.test.js`): cover no-op / fresh create / correct skip / wrong target rebuild / broken rebuild / realpath post-validation
- **e2e validation**: `/tmp` scratch project run linkGlobalConfig → readlink = relative → `git check-ignore` hit → realpath resolve → doctor segment shows ok
- **Implementation found + fixed 2 real bugs beyond task scope**:
  - macOS `/tmp → /private/tmp` alias trap (need realpath both sides)
  - `fs.existsSync` follows symlinks vs broken symlink detection (need lstatSync)
- Docs sync `docs/platform-integration.md` adds "Global config symlink and portability" section
- commit: `1e736f2` / `dde5cf5` (merge)

#### 4. Bounded Monitor Reconciliation (M-015 / ACN/P-005)
- **Core innovation**: Strict separation of **Task state** vs **execution-attempt disposition**
- 5 attempt states:
  - `attempt_active` / `attempt_review_ready` / `attempt_attention_required` / `attempt_closed` / `attempt_inconsistent`
- `lib/attempt-disposition.js`: pure derivation + read-only projection
- **Heartbeat terminal anomaly: notify once, then auto-pause** (avoid noise)
- **Fenced manual reconciliation**:
  - Requires fresh lease + fencing token + evidence, fail-closed if any missing
  - `reconcileAttemptForReadiness` entry point
- 10 new tests + 479/479 coordination suite no regression
- commits: `b0c596d` / `2651f36` (P-005 main line)

#### 5. Host-Neutral Notification (ACN/P-003)
- Vendor-neutral **Host Wakeup Adapter** + stdio/JSONL transport

- Production notification lifecycle integration (`6855cd9`)
- Notification CLI public contract + thin adapter (`efed4ef`)
- Codex Adapter structured context + deferred + ACK eligibility
- Claude Code / generic Agent public CLI reporting + launch context
- commits: `0d73da2` / `efed4ef` / `6855cd9` / `ae446bd`

#### 6. Agent Skills Ecosystem Fusion 🆕 (90e9cd5, Ref M-017)
