## 中文版

### 重大特性 (Major Features)

#### 1. proposal-share — 提案包共享工作流 (T-H14)

把「标准目录结构 + 文件可移植」变成一键操作：导出 / 导入可移植提案包
（proposals + missions + topology + 双仓 peer 卷），支持跨开发者、跨仓库共享提案目录。

- **引擎**: `.agent/scripts/proposal-share.js`（`export / import / verify` 三子命令）
  - 绝对路径 `@ROOT:<repo>@` token 化（`cross_project_peers` / `relations.md` / `index.md` / topology `host_root`）
  - 符号链接解引用进包 + 按 MANIFEST 重建（双仓共享决策镜像）
  - 双仓联合提案自动发现并打包 peer 卷（topology / frontmatter / 路径扫描 / `--peers`）
  - 关联 missions 自动收集（引用 `projects/<slug>` 的 mission-plan 或 `--missions` / `--all-missions`）
  - MANIFEST v1.0 + README 交接说明；结构校验；导入合并不删文件；`--dry-run` 零写入
- **CLI**: `cortex-agent proposal-share <export|import|verify>`
- **工作流**: `.agent/workflows/proposal-share.md`（zh/en）；与 `/handoff` 互补（提案目录走包、运行时状态走 handoff）
- **规则**: `.agent/rules/proposal-structure.md` 新增「跨仓库 / 跨开发者共享」章节（zh/en 模板同步）
- **模板分发**: `templates/{zh,en,_shared}/.agent/scripts/proposal-share.js`（4 处 sha256 一致）
