## Backward Compatibility

- `cortex-agent init --mode code` 行为与 v1.10.0-rc.1 完全一致
- 现有 v1.10.x 项目 `cortex-agent update` 升级零影响(shadow 路径)
- `update --mode general` 暂不允许跨模式升级(v2.0.0 引入 `cortex-agent migrate` 替代)
- 所有 v1.10.x 已有子命令(`init / update / upgrade / session / task / event / lease / secrets / query / 等`)函数体零修改

## Known Limitations

- `cortex-agent memory` CLI 暂未 ship(M-002 MS-002 实施后可用)
- `cortex-agent agent register` 暂未 ship(M-002 MS-003 实施后可用)
- procedural memory 仍推 v1.12(M-002 MS-002 只 ship episodic + semantic)
- 5 adapters + 1 MCP bridge(Claude Code / Codex / Cursor / Pi / MiniMax)完整实施留 v1.12+ 或 v2.0(本 rc 只 ship 框架 + 至少 1 个示例 adapter)
- **cross-host 适配**:host 主动调用 `cortex-agent session host-switch` 未做(留 v1.12+)
- **跨厂商 agent 联邦**:`agents/capabilities/` 标准化 capability 描述未 ship(留 v2.0)

## Upgrade Path

- v1.10.0-rc.1 → v1.11.0-rc.1:`npx cortex-agent update` 即可,零影响
- v1.11.0-rc.1 → v1.11.0 GA(待发):同样 `npx cortex-agent update`
- v1.11.0 → v2.0.0(未来):走 `cortex-agent migrate` 跨模式升级,提供 dry-run
